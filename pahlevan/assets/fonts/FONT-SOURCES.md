# فونت‌های معرفی پهلوان

برای درخواست مالک پروژه جهت استفاده از دانا و مربع، نسخه‌های زیر از دارایی‌های محلی موجود او کپی شدند. فایل اصلی فونت‌ها تغییر یا بازنام‌گذاری نشده و هیچ فایل فونت از یک CDN ناشناس دریافت نشده است.

| متن دانا ۵۰۰ | DanaFaNum-Medium.woff2 |
| متن دانا ۶۰۰ | DanaFaNum-DemiBold.woff2 |
| متن دانا ۷۰۰ | dana-fanum-bold.woff2 |
| تیتر مربع ۵۰۰ | Morabba-Medium.woff2 |
| تیتر مربع ۷۰۰ | Morabba-Bold.woff2 |

این قلم‌ها فقط برای سند معرفی همراه شده‌اند؛ قلم و فایل‌های برنامهٔ پهلوان تغییر نکردند. فایل قبلی Vazirmatn و مجوز همراه آن نیز جدا محفوظ‌اند.
